# خطة استكمال المنهج

## المكتمل في النسخة الحالية

ستة دروس تمهيدية مراجعة: الحجج، الاستدلال الشرطي، الضرورة والكفاية، وأنواع الاستدلال، والروابط المنطقية وجداول الصدق، والمكممات ونطاق النفي. وهي بداية المسار وليست تغطية شاملة. يقتصر درس المكممات على جمل بمكمم واحد؛ المكممات المتداخلة والبراهين غير مكتملة، والإبستمولوجيا وفلسفة العلم والسببية وتصميم التجارب ما زالت مخططة.

## الترتيب المقترح

| الوحدة | نواتج التعلم | نشاط ومعيار إكمال |
| --- | --- | --- |
| 4: أنواع الاستدلال (مضاف) | التمييز بين Deduction وInduction وAbduction؛ فرق اللزوم والترجيح | تصنيف أمثلة مع تفسير ما قد يغير النتيجة |
| 5: منطق القضايا (مضاف) | النفي والعطف والفصل الشامل والحصري والتكافؤ والأقواس؛ التناقض والصدق المنطقي | بناء جداول صدق وصيغ ذات ثلاثة متغيرات |
| 6: المكممات واللغة (مضاف) | كل/بعض، نطاق النفي، ∀ و∃؛ فصل العكس عن المقابل النقيض | ترجمة وتوليد مثال مضاد مع مجال واضح |
| 7: البرهان والمغالطات | براهين قصيرة، مقدمات ضمنية، فرق المغالطة الشكلية وغير الشكلية | إصلاح حجة وشرح الافتراض المضاف |
| 8: المعرفة والتبرير | الاعتقاد والمعرفة والدليل، حدود اليقين | مقارنة تبريرات مع اعتراضات |
| 9: فلسفة العلم | الفرضية والتنبؤ والتكذيب والمساعدات والنموذج | تحليل تجربة يمكن أن تخالف تنبؤًا مشروطًا |
| 10: الاحتمال وBayes | الاحتمال الشرطي ومعدل الأساس وقوة الدليل | تكرارات طبيعية واختبار تشخيصي افتراضي |
| 11: الاستدلال السببي | الارتباط والسببية والمربكات والوساطة والتدخل | رسم DAG بسيط واختيار متغيرات الضبط |
| 12: تصميم التجارب | الضوابط والعشوائية والتعمية وحجم العينة وعدم اليقين والتكرار | خطة اختبار لفرضية محددة مع حدود الاستنتاج |

كل وحدة تحتاج مراجعة المصادر، ومثالًا محلولًا، وحالات مضادة، وتمارين بتعليل، ومراجعة علمية وبصرية قبل وصفها بأنها مكتملة. الخطوة التالية: الوحدة 7 عن البراهين القصيرة والمقدمات الضمنية والمغالطات.
