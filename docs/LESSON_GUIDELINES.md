# قواعد كتابة الدروس

1. ابدأ بهدفين أو ثلاثة يمكن للمتعلم تطبيقهما، واذكر المتطلبات السابقة والمجال: أعداد صحيحة، منطق كلاسيكي، أو بروتوكول تجريبي محدد.
2. قدّم المعنى بالعربية ثم المصطلح الإنجليزي، ثم مثالًا محسوسًا، ثم الصياغة الرمزية المعزولة من اليسار لليمين.
3. افصل Truth عن Validity عن Soundness، والشرط المادي عن السببية، والتوافق مع الفرضية عن إثباتها.
4. لكل مفهوم: مثال محلول، وحالة مضادة أو حدية، وتمرين انتقال إلى سياق مختلف. تجنب خيارات غامضة أو أكثر من جواب صحيح دون تنبيه.
5. اكتب تعليلًا للصواب والخطأ؛ لا تكتفِ بعلامة أو لون. أضف إجابة مقترحة للسؤال المفتوح قابلة للكشف بعد المحاولة.
6. لا تُطلق حكم ضرورة أو كفاية تجريبيًا بلا تحديد السكان والظروف والتدخل والقياس. افصل نقص الدليل عن نقض الادعاء.
7. المصادر العلمية أصلية قدر الإمكان: المؤلف والسنة ورابط مباشر، مع وصف ما يدعمه المصدر وما لا يدعمه. لا تنسخ نصوص المراجع أو رسومها دون ترخيص.
8. الرسوم والتفاعلات تكشف علاقة أو حالة مضادة؛ لا تستخدم منحنيات عصبية مصطنعة كأنها بيانات أو محاكاة موثقة. سمِّ النماذج التخطيطية صراحة.
9. اختبر كل حالة منطقية ممكنة للمختبر الصغير، وكل إجابة في التمرين، والحفظ والاستعادة وعدم توفر التخزين.
10. حافظ على الاستخدام بلوحة المفاتيح، وتسميات المدخلات، وaria-live للتغذية الراجعة، وتباين مناسب، واتجاه RTL والرموز LTR. احترم الحركة المخفضة والطباعة والهاتف.

## قالب تسلسلي

العنوان ← أهداف التعلم والمتطلبات ← المشكلة المحفزة ← التعريف والرموز ← مثال محلول ← مختبر أو شكل عند الحاجة ← حالات مضادة وحدود ← تمارين متدرجة ← سؤال مفتوح وإجابة مقترحة ← مصادر ← رابط السابق والتالي.

عند إضافة درس حدّث الفهرس وخطة المنهج والاختبارات. لا تغيّر معنى تمرين منشور مع الاحتفاظ بنفس مفتاح التخزين. الأسئلة المصححة مقياس تدريب محدود وليست شهادة إتقان شامل.
