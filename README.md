# المنطق والاستدلال العلمي

منهج عربي بمصطلحات إنجليزية، يعمل محليًا دون اتصال. الإصدار 0.5.1 يحتوي على **خمسة دروس تأسيسية و26 تمرينًا مصححًا وخمسة مختبرات تفاعلية**؛ ولا يمثل منهجًا مكتملًا في المنطق أو فلسفة العلم.

## التشغيل

افتح `index.html` مباشرة في المتصفح. لا يحتاج المتعلم إلى Node أو npm أو تنزيل مكتبات. الخطوط والتصميم والبرامج محلية، ولا يحمّل الموقع موارد خارجية. روابط المراجع فقط تحتاج الإنترنت عند فتحها.

تبقى الدروس والقاموس صفحات منفصلة وهي مصدر التحرير الوحيد. عند فتح ملف من معاينة الشات قد لا تعمل التفاعلات. افتح صفحة الدرس في متصفح مع الحفاظ على مجلد `assets` والملفات المصاحبة. عند عدم تفعيل التصحيح يظهر تنبيه، ويظل الحل اليدوي متاحًا أسفل كل تمرين. لم نختبر معاينة الشات نفسها، فلا نجزم بسبب المنع فيها.

## توليد نسخة للمشاركة

```sh
npm run export:single
```

يحدّث القاموس من مصدر تعريفاته، ثم يجمع أحدث صفحات الدروس والتصميم والبرامج في `dist/course.html`. لا يحتاج الملف الناتج إلى ملفات مجاورة أو اتصال بالإنترنت. افتحه في متصفح؛ معاينة الشات قد لا تشغّل التفاعلات حتى في ملف مكتمل.

**عدّل الملفات الأصلية فقط، ثم أعد تشغيل الأمر. لا تعدّل `dist/course.html` يدويًا.** المجلد `dist/` مستبعد من Git ويمكن إعادة توليده؛ لا توجد نسختان من المحتوى تحتاجان إلى مزامنة يدوية. روابط الأقسام والقاموس تتحول إلى روابط داخل الملف. تخزين التقدم قد يختلف بين الموقع المنفصل وملف المشاركة بسبب سياسات المتصفح.

## المراجعة والمصطلحات

- كل درس مقسم إلى أقسام ذات روابط ثابتة. اضغط `#` بجوار العنوان ثم احتفظ بالرابط أو أضفه إلى مفضلة المتصفح. لا توجد خدمة مزامنة أو حساب مستخدم.
- الضغط على المصطلح المسطّر يفتح تعريفه داخل الصفحة. يمكن إغلاقه بزر الإغلاق أو Escape أو لمس المساحة الخارجية، ثم تعود إلى موضع القراءة. توجد روابط للشرح الأصلي وللقاموس.
- `glossary.html` قاموس مستقل يحوي 44 مصطلحًا بالعربية والإنجليزية، مع بحث وروابط للأقسام. عند تعطل JavaScript تفتح الضغطة العادية إطار تعريف داخل الصفحة باستخدام popover في المتصفحات الحديثة. ويظل الانتقال إلى القاموس أو الشرح الكامل رابطًا مستقلًا داخل الإطار. لا نخصص سلوكًا للضغطة الطويلة أو المزدوجة أو الزر الأيمن؛ تبقى هذه الإيماءات للمتصفح. معاينة الشات قد تمنع ميزات إضافية، ولم نختبرها مباشرة.
- مصدر التعريفات المشترك هو `assets/terms.js`؛ لا تكرر التعريفات يدويًا في الصفحات. لتحديث القاموس وروابط المصطلحات بعد تحرير الدروس أو التعريفات شغّل:

```sh
npm run references:sync
```

هذا الأمر يولّد صفحة `glossary.html` من مصدر التعريفات المشترك، ويضيف روابط التعريفات إلى نصوص الدروس. تبقى ملفات HTML/CSS/JS منفصلة وقابلة للتحرير. حافظ على معرفات الأقسام عند تحرير العناوين حتى لا تنكسر الروابط المحفوظة.

للتطوير باستخدام Node.js 22 أو أحدث:

```sh
npm ci
npm start
```

ثم افتح http://127.0.0.1:4173 . لا تحتاج قراءة الموقع إلى عملية بناء: HTML/CSS/JS هي ملفات الموقع النهائية، ولا مبرر لإضافة إطار عمل حاليًا. أوامر npm مخصصة للتطوير المحلي وتحديث المراجع والتصدير والاختبارات.

## الاختبارات

```sh
npm test
npm run test:browser
```

الأول يفحص جدول الصدق والأشكال الأربعة واتساق التمارين والروابط المحلية. الثاني يستخدم Playwright مع Chrome المثبت على Windows بالمسار الموجود في `playwright.config.cjs`. على جهاز آخر عدّل `executablePath`، أو احذفه وثبّت Chromium بـ `npx playwright install chromium`.

اختبارات المتصفح تشمل جميع التمارين، القيم الأربع للمختبرات، إعادة التحميل، إجمالي التقدم، منع التخزين، الوضع الداكن، الحركة المخفضة، عرض 360 و1280 بكسل وفتح `file://`. صور المراجعة تتولد في `work/screenshots/` ولا تدخل Git. لا تتضمن هذه الاختبارات مراجعة فعلية بقارئ شاشة أو اختبارًا شاملًا لكل المتصفحات.

## الملفات والإضافة

- `lessons/`: صفحات الدروس.
- `assets/style.css`: التصميم وRTL والطباعة والحركة المخفضة.
- `assets/logic.js`: الدوال المنطقية المشتركة بين المختبرات والاختبارات.
- `assets/course.js`: التصحيح والتقدم والوضع الداكن.
- `tests/`: اختبارات المحتوى والمنطق والمتصفح.
- `tools/serve.cjs`: خادم تطوير محلي مرتبط بـ127.0.0.1.
- `docs/`: المراجعة وخطة المنهج وقواعد التأليف.

عند إضافة تمرين، استخدم معرفًا ثابتًا وفريدًا، وأضفه إلى `quizIds` في `assets/course.js`، وحدّث إجمالي الفهرس والاختبارات. لا تغيّر معنى معرف قديم دون ترحيل التخزين أو تغيير نسخته.

## التقدم والخصوصية

آخر إجابة **تم التحقق منها** تحدد الإتقان؛ مجرد المحاولة لا يعني الإجابة الصحيحة. عند إعادة اختيار إجابة لا يتغير التقدم حتى التحقق منها. تُستعاد الإجابة والتغذية الراجعة بعد إعادة التحميل.

التخزين محلي ولا تُرسل البيانات إلى خادم. إذا منعه المتصفح، تعمل التمارين وتبقى الإجابات في ذاكرة الصفحة حتى مغادرتها، ويظهر تنبيه. مفاتيح النسخة الجديدة تبدأ بـ`logic-course-v2-`؛ لا تُحذف مفاتيح النسخة القديمة ولا تُحتسب محاولاتها كإتقان. الحفظ في `file://` يختلف بين المتصفحات وقد لا يكون مشتركًا بين الصفحات؛ استخدم `npm start` لتقدم موحد موثوق في الفهرس. حذف بيانات الموقع أو تغيير المتصفح/العنوان يفصل التقدم.

## Git

المستودع محلي؛ لم يُنشأ remote أو يُنشر الموقع. يتجاهل Git المكتبات والنتائج والملفات المؤقتة، ويثبت ملف القفل إصدارات أدوات الاختبار. قبل أي commit راجع `git diff` وشغّل الاختبارات. لا توجد رخصة إعادة توزيع محددة للمحتوى الأصلي بعد؛ يجب حسمها قبل النشر العام.
